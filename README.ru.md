## Возможности

- **Заметки-списки** – добавляйте пункты через `+`; нажатие на карандашик рядом с пунктом зачёркивает его и делает тусклым (повторное нажатие возвращает).
- **Напоминания** – выберите дату и время, напишите описание. В назначенный момент экран затемняется, появляется большая карточка и звучит сигнал.
- **Закрепление** – закреплённая заметка стоит на рабочем столе под всеми окнами и не двигается. Незакреплённую можно перетащить куда угодно, она лежит поверх окон.
- **Создание с рабочего стола** – правый клик по рабочему столу → *Создать заметку* / *Создать напоминание*. Заметка появляется под курсором.
- **Авторазмер** – заметка сама становится уже или шире в зависимости от текста.
- **Настройки** – 6 готовых тем и своя (цвет фона и цвет элементов), любой установленный шрифт и размер, своя мелодия (mp3 / wav), формат даты `ДД.ММ.ГГГГ` или `ММ.ДД.ГГГГ`.
- **Поля даты и времени с маской** – формат `00.00.0000` / `00:00` нельзя сломать, удалённые цифры превращаются в `0`.
- **Живёт в трее** как модуль PowerToys, есть автозапуск, запускается в одном экземпляре.

## Установка (для пользователей)

1. Откройте страницу [**Releases**](https://github.com/ArtloK-7516405/DesktopNotes/releases/latest).
2. Скачайте файл **`DesktopNotes-Setup.exe`**.
3. Запустите его и следуйте мастеру установки (права администратора не нужны – установка для текущего пользователя).
4. На последней странице оставьте галочку «Запустить Desktop Notes». В системном трее появится значок.

> **«Windows защитила ваш компьютер» (SmartScreen)?** Установщик не подписан сертификатом, поэтому Windows может предупредить. Нажмите **Подробнее → Выполнить в любом случае**.

Требования: Windows 10 / 11, 64-бит. .NET встроен – ничего дополнительно ставить не нужно.

## Как пользоваться

| Что нужно | Как сделать |
|---|---|
| Создать заметку | Правый клик по рабочему столу → **Создать заметку** (или значок в трее → *Новая заметка*) |
| Создать напоминание | Правый клик по рабочему столу → **Создать напоминание** |
| Переместить заметку | Перетащить мышью (заметка должна быть откреплена) |
| Закрепить / открепить | Нажать на булавку вверху заметки |
| Удалить заметку | Нажать `×` в правом верхнем углу |
| Отложить сигнал на 5 минут | Нажать `–` на карточке напоминания |
| Закрыть напоминание | Нажать `×` или `Esc` |
| Открыть настройки | Двойной клик по значку в трее или меню «Пуск» → *Desktop Notes* |

### Windows 11: где «Создать заметку»?

Windows 11 прячет сторонние пункты меню рабочего стола в **«Показать дополнительные параметры»** (или нажмите **Shift + правый клик**).
Чтобы пункты были сразу на виду, откройте *Настройки* и включите **«Показывать «Создать заметку» сразу в меню рабочего стола»** – это переключит всю систему на классическое меню Windows 10 (Проводник перезапустится). Снимите галочку, чтобы вернуть как было.

### Где хранятся данные?

`%AppData%\DesktopNotes\data.json` – заметки и настройки. Скопируйте этот файл, чтобы перенести заметки на другой компьютер.

### Удаление

*Параметры → Приложения → Установленные приложения → Desktop Notes → Удалить*. Пункты меню и автозапуск удаляются автоматически. Ваши заметки в `%AppData%\DesktopNotes` сохраняются.

## Сборка из исходников

Нужны [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) и [Inno Setup 6](https://jrsoftware.org/isdl.php).

```bat
git clone https://github.com/ArtloK-7516405/DesktopNotes.git
cd DesktopNotes
build.bat
```

Установщик появится в `installer\DesktopNotes-Setup.exe`. Чтобы просто запустить приложение при разработке:

```bat
dotnet run --project src\DesktopNotes.csproj
```

```

  Program.cs         точка входа, трей, один экземпляр, таймер напоминаний

  Models.cs          данные, темы, хранилище
  AlarmSound.cs      сигнал
installer.iss        скрипт Inno Setup
build.bat            сборка в один клик
.github/workflows    автоматическая сборка релиза
```

## Возможные проблемы

- **`build.bat`: «NuGet.Protocol ... не найден»** – установка .NET SDK повреждена. Удалите все .NET SDK, удалите папку `C:\Program Files\dotnet\sdk`, установите .NET 8 SDK заново и проверьте `dotnet --version`.
- **Пунктов меню нет на рабочем столе** – см. раздел про Windows 11 выше.
- **Нет звука напоминания** – проверьте громкость и файл мелодии в настройках (кнопка *Стандартный* вернёт встроенный сигнал).
